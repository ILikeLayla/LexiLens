Multisensory Dyslexia Reading Assistant

Camera-based reading tool with OCR, AI text restructuring, TTS, and visual highlighting

Client Layer

  • • Mobile/web camera — captures printed materials
  • • Highlighted text display — scannable sections with colour-coded highlighting
  • • Audio output — synchronized read-along via speaker/headphones
  • • Built with React Native / Flutter (cross-platform)

Core Processing

  • • Tesseract / EasyOCR — extracts text from camera images
  • • LLM-powered restructuring — rewrites passages into short, clear sections
  • • TTS (ElevenLabs / gTTS) — natural-sounding read-aloud
  • • Visual highlighting — syllable/phoneme colour overlays for multisensory support

Data & AI

  • • LLM API (OpenAI / Anthropic / local) — text simplification & rewording
  • • User preferences — font size, reading speed, colour theme
  • • Reading history — previously scanned materials, progress tracking
  • • SQLite / PostgreSQL — lightweight local or cloud storage
