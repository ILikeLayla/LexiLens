Higgs Audio v3 TTS — the real story

  • • Not a simple crate like tts-rs or espeak-rs
  • • It's a 4B-parameter multimodal LLM (higgs_multimodal_qwen3) — 36 layers, 2560 hidden dim, GQA 32/8
  • • Generates 8 codebooks × 1026 vocab audio tokens at 25 fps via delay-pattern decoding
  • • Needs a dedicated inference server: SGLang-Omni or vLLM-Omni
  • • Exposes OpenAI-compatible POST /v1/audio/speech API
  • • Supports streaming SSE — sub-second time-to-first-audio
  • • 9.3 GB disk, ~24 GB VRAM GPU recommended
  • • 100+ languages, zero-shot voice cloning, emotion/style/prosody control tokens
  • • License: research and non-commercial only

How Rust integrates with Higgs

  • • gpui calls lexilens_server::handle_tts(text) — direct fn call
  • • Handler sends reqwest::Client POST to http://127.0.0.1:8000/v1/audio/speech
  • • Higgs server returns WAV bytes (or SSE stream of base64 WAV chunks)
  • • Rust receives bytes → writes to Vec<u8> → stores in ReadingModel
  • • gpui triggers rodio playback from the WAV buffer
  • • Streaming path: SSE → accumulate chunks → play as they arrive

Two-process architecture

# Terminal 1 — Higgs TTS Server
docker run --gpus all --shm-size 32g \
  -p 8000:8000 \
  lmsysorg/sglang-omni:dev

sgl-omni serve \
  --model-path bosonai/higgs-audio-v3-tts-4b \
  --port 8000

# Terminal 2 — LexiLens
cargo run --bin lexilens-gpui

# gpui auto-connects to localhost:8000
# Uses:
#   POST /v1/audio/speech → TTS
#   POST /v1/audio/speech?stream=true → SSE stream
  • • Higgs runs once in the background, LexiLens starts independently
  • • On LexiLens startup, it pings Higgs — if unavailable, falls back to espeak-rs or shows a warning
  • • Higgs can also serve other apps (not tied to LexiLens)

Rust TTS decision matrix

Option Quality Latency GPU Deps
Higgs v3 High ~600ms 24GB+ Docker+Python
espeak-rs Basic ~5ms None Pure Rust
Cloud API Strong ~200ms None reqwest
candle/PyO3 Medium ~100ms 8GB+ Native Rust

Design the TTS layer as a trait — swap implementations at runtime. Start with espeak-rs for dev, add Higgs when the GPU is available.
